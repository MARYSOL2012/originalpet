INSTRUCCIONES PARA AGREGAR IMÁGENES A THE ORIGINALS PETS:

FOTO DE PERFIL:
1. Coloca la imagen de perfil en esta carpeta
2. Renómbrala como "perfil.png" (ya existe en el directorio raíz)
3. Formatos soportados: JPG, PNG, WEBP
4. Tamaño recomendado: 400x400 píxeles o más (cuadrada)
5. La imagen se ajustará automáticamente a forma circular

IMÁGENES ADICIONALES RECOMENDADAS:
- logo.png: Logo de la empresa
- productos/: Carpeta para imágenes de productos
- mascotas/: Carpeta para fotos de mascotas felices
- equipo/: Carpeta para fotos del equipo
